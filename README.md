# 💰 Finans: Landing Page Financeira

>  O Finans é uma interface institucional moderna projetada para simular um portal de serviços financeiros, focada em usabilidade e clareza de informações.

<br>

## 🎯 Objetivo do Projeto
Este projeto foi desenvolvido para aplicar conceitos de **Bootstrap 4**, como o sistema de grids responsivo, componentes de navegação e estilização de formulários, criando uma landing page que passa credibilidade ao usuário.

<br>

## 🚀 Tecnologias e Ferramentas
* **Framework:** Bootstrap 4 (Grid System e Componentes)
* **Linguagem:** HTML5 e CSS3 customizado
* **Lógica:** JavaScript (Manipulação de DOM para cálculos financeiros)
* **Ícones:** Font Awesome para interface visual
